# Техническое задание на создание сайта-портфолио «АннаСфера»

## 1. Общая информация

Необходимо создать современный одностраничный сайт-портфолио «АннаСфера».

Сайт должен представлять Анну как специалиста, который работает с нейросетями, визуальным контентом, видео, текстами, сайтами и простыми веб-приложениями.

Основная идея проекта — объединить в одном личном бренде творчество, искусственный интеллект и современные digital-инструменты.

Сайт не должен позиционировать Анну исключительно как веб-разработчика. Он должен показывать полный спектр услуг: от нейрофотосессий и визуалов до создания сайтов, приложений и комплексных digital-проектов.

## 2. Цели сайта

Сайт должен:

— представить личный бренд «АннаСфера»;
— рассказать об услугах;
— показать примеры выполненных проектов;
— продемонстрировать работу с нейросетями и вайбкодингом;
— вызывать доверие у потенциальных клиентов;
— помогать посетителю быстро выбрать нужную услугу;
— мотивировать посетителя связаться с автором и обсудить проект.

## 3. Целевая аудитория

Основная аудитория сайта:

— частные клиенты;
— эксперты и авторы личных блогов;
— владельцы малого бизнеса;
— специалисты, которым нужен визуальный контент;
— люди, которым нужны нейрофотосессии и персональные изображения;
— клиенты, которым нужны поздравительные и атмосферные видеоролики;
— заказчики, которым нужен лендинг, сайт-портфолио или простое приложение;
— люди, которые хотят использовать нейросети для личных или рабочих задач.

## 4. Формат сайта

Тип сайта: одностраничный сайт-портфолио.

Все основные разделы располагаются на одной странице.

Переход между разделами осуществляется через меню с плавной прокруткой.

Сайт должен корректно отображаться:

— на компьютере;
— на планшете;
— на смартфоне.

## 5. Технологии

Использовать:

— HTML5;
— CSS3;
— JavaScript.

Создать отдельные файлы:

— `index.html`;
— `style.css`;
— `script.js`.

Не использовать:

— React;
— Vue;
— Bootstrap;
— другие фреймворки;
— сложные библиотеки;
— серверную часть.

Код должен быть понятным, структурированным и содержать комментарии.

## 6. Структура сайта

Сайт должен включать следующие разделы:

1. Шапка и меню.
2. Первый экран.
3. Обо мне.
4. Услуги.
5. Подход к работе.
6. Портфолио.
7. Преимущества «АннаСферы».
8. Призыв к действию.
9. Контакты.
10. Подвал сайта.

# 7. Шапка сайта

В шапке разместить логотип:

**АннаСфера**

Рядом с логотипом можно использовать небольшую подпись:

**AI & Digital**

Добавить пункты меню:

— Главная;
— Обо мне;
— Услуги;
— Подход;
— Проекты;
— Контакты.

Шапка должна быть закреплена в верхней части экрана.

При прокрутке страницы фон шапки должен становиться более плотным, чтобы текст меню оставался читаемым.

Активный раздел меню должен визуально выделяться.

На мобильных устройствах обычное меню должно заменяться бургер-меню.

При открытии мобильного меню должна появляться вертикальная панель со ссылками на разделы сайта.

После выбора пункта мобильное меню должно автоматически закрываться.

Описание:

— минималистичную иконку;

— описание;
— лёгкий визуальный акцент;
— анимацию при наведении.

— немного подниматься;

— менять цвет границы;
— усиливать тень.

Анимация должна быть плавной и ненавязчивой.

# 17. Дизайн сайта

Общее направление:

— современное;
— творческое;
— технологичное;
— атмосферное;
— профессиональное;
— женственное, но не приторное;
— минималистичное, но не пустое.

Сайт должен выглядеть как авторское digital-портфолио, а не как стандартный шаблон.

## Цветовая палитра

Использовать:

— светлый основной фон;
— тёмный цвет текста;
— глубокий фиолетовый, сливовый или сине-фиолетовый акцент;
— мягкие дополнительные оттенки;
— светлые градиенты.

Не использовать:

— большое количество ярко-розового;
— блёстки;
— цветочный декор;
— детские элементы;
— слишком много разных цветов.

## Типографика

Использовать:

— крупные выразительные заголовки;
— хорошо читаемый основной текст;
— заметные акцентные подписи;
— достаточные интервалы между строками и блоками.

Допускается подключение современного шрифта через Google Fonts.

Не использовать больше двух семейств шрифтов.

## Карточки

Карточки должны иметь:

— аккуратное скругление;
— тонкую границу или лёгкую тень;
— достаточные внутренние отступы;
— плавные эффекты при наведении.

## Композиция

Использовать:

— много свободного пространства;
— крупные блоки;
— асимметричное расположение отдельных элементов;
— сочетание текста и изображений;
— визуальные акценты;
— понятную иерархию.

# 18. Анимации

Добавить умеренные анимации:

— плавное появление разделов при прокрутке;
— лёгкое движение карточек при наведении;
— увеличение изображений проектов;

— чрезмерное количество анимаций;
— эффекты, мешающие чтению;
— тяжёлые анимационные библиотеки.

Анимации должны работать через CSS и JavaScript.

— обычное;
— наведение;
— нажатие;
— фокус.

# 20. Адаптивность

Сайт должен корректно работать при ширине экрана:

— от 320 пикселей;
— на смартфонах;
— на планшетах;
— на ноутбуках;
— на больших мониторах.

На мобильных устройствах:

— текст не должен выходить за границы экрана;
— заголовки должны уменьшаться;
— карточки должны располагаться в один столбец;
— кнопки должны быть удобными для нажатия;
— меню должно превращаться в бургер;
— изображения не должны искажаться;
— горизонтальная прокрутка должна отсутствовать.

---

# 21. Требования к коду

HTML должен содержать:

— семантические теги;
— понятные названия классов;
— корректную структуру заголовков;
— атрибуты `alt` у изображений;
— якорные ссылки для навигации.

CSS должен содержать:

— переменные для основных цветов;
— переменные для размеров и скруглений;
— адаптивные медиазапросы;
— понятные комментарии;
— логичное разделение стилей по блокам.

JavaScript должен отвечать за:

— мобильное меню;
— активный пункт навигации;
— фильтрацию проектов;
— анимацию появления элементов;
— кнопку «Наверх»;
— проверку и демонстрационную отправку формы;
— вывод текущего года.

Не дублировать одинаковый код.

Не добавлять неиспользуемые функции.

---

# 22. Возможность редактирования

В коде необходимо добавить комментарии, показывающие:

— где заменить фотографию;
— где добавить ссылки на Telegram, VK и MAX;
— где изменить тексты;
— где заменить изображения проектов;
— где добавить новую услугу;
— где добавить новый проект;
— где изменить основные цвета сайта;
— где изменить контактные данные.

Контент должен легко редактироваться без полной переработки сайта.

# 23. Результат работы

В результате необходимо создать полностью готовый рабочий проект из трёх файлов:

— `index.html`;
— `style.css`;
— `script.js`.

Все файлы должны быть полностью заполнены кодом и связаны между собой.

Сайт должен открываться локально через файл `index.html` без дополнительной установки зависимостей.

Перед завершением необходимо проверить:

— работу всех ссылок;
— работу меню;
— адаптивность;
— фильтрацию проектов;
— форму обратной связи;
— отсутствие ошибок в консоли;
— отображение сайта на мобильной ширине;
— отсутствие горизонтальной прокрутки.

Сначала создай полную рабочую версию сайта. После этого кратко перечисли созданные файлы и основные функции проекта.
